# Environment Fund Brand Assets

This directory is reserved for the official Environment Fund brand assets used by the prototype.

## Required structure

```text
assets/brand/
├── logos/
├── patterns/
└── graphic-elements/
```

## Important rules

- Only official, approved SVG assets may be added.
- Do not redraw, trace, modify, recolor, or recreate the logo.
- Do not commit licensed font files such as OTF, TTF, WOFF, or WOFF2.
- Runtime copies of the approved assets must also be placed under `src/public/brand/` using the same categorization.
