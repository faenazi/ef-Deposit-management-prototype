# EF Brand Experience

This folder is the visual source of truth for the Investment Deposit Management Platform prototype.

All UI/UX, design-system, frontend, data-visualization, and quality-review work must comply with these documents before implementation begins.

## Authority order

1. Official Environment Fund visual identity guideline and approved assets.
2. `00-brand-source-of-truth.md`.
3. Product-specific brand and UX documents in this folder.
4. Page design specifications.
5. Frontend implementation decisions.

When a conflict exists, the higher authority wins.

## Documents

- `00-brand-source-of-truth.md` — official identity facts and non-negotiable rules.
- `01-design-philosophy.md` — intended visual and experience character.
- `02-brand-application.md` — practical use of logos, patterns, and identity elements.
- `03-color-system.md` — brand and semantic UI color tokens.
- `04-typography.md` — bilingual and financial typography rules.
- `05-iconography.md` — icon rules.
- `06-pattern-system.md` — controlled pattern and radial-element usage.
- `07-data-visualization.md` — charts and financial data rules.
- `08-motion-system.md` — motion and interaction rules.
- `09-responsive-strategy.md` — responsive design behavior.
- `10-brand-compliance-checklist.md` — review gate for every screen.
- `11-product-design-dna.md` — product-specific design principles.

## Non-negotiable outcome

The platform must feel like a premium Saudi government treasury product designed for the Environment Fund. It must not resemble a generic SaaS admin template.
