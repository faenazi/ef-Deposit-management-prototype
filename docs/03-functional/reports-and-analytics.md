# Reports and Analytics

## Purpose

Provide decision-oriented portfolio and process analysis using prototype data.

## Required Analysis Areas

- Portfolio value and expected return.
- Weighted average rate.
- Distribution by bank.
- Distribution by tenor.
- Maturity ladder.
- Upcoming maturities.
- Request pipeline by stage.
- Approval turnaround time.
- Returned and rejected requests.
- Bank participation and response rate.
- Offer-rate comparison.
- Portfolio concentration indicators.

## Report Experience

- Use a small number of meaningful charts per page.
- Pair charts with concise financial summaries.
- Provide filters for period, bank, tenor, amount range, request status, and deposit status.
- Keep filter behavior consistent across reports.
- Allow drill-through to the related request or deposit list.
- Use realistic Arabic labels and Saudi Riyal values.

## Prototype Reports

1. Executive portfolio overview.
2. Deposit maturity report.
3. Bank concentration report.
4. Investment request pipeline report.
5. Bank offers and competitiveness report.
6. Approval and execution performance report.

## Rules

- Analytics are calculated from the local mock-data source.
- Metrics must reconcile with list views.
- No external BI service or real export integration is required.
- Avoid decorative charts that do not support a decision.
