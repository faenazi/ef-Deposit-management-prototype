# Investment Requests

## Purpose

Provide an operational list of investment requests across preparation, approval, execution, completion, rejection, and cancellation.

## Default View

Use a professional data grid with a concise summary bar.

## Required Columns

- Request number
- Request title
- Amount and currency
- Tenor
- Recommended bank when available
- Current status
- Current owner or responsible group
- Draft completion percentage when applicable
- Created date
- Last update
- Priority

## Filters

- Request number or title
- Status
- Current stage
- Assigned user or group
- Amount range
- Tenor
- Bank
- Creation date
- Maturity date
- Priority
- Draft owner

## Predefined Views

- مسوداتي
- معادة للاستكمال
- بانتظار الاعتماد
- تحت التنفيذ
- مكتملة
- مرفوضة أو ملغاة
- طلبات تتجاوز 100 مليون ريال

## Actions

- Create a new request
- Open the request file
- Resume an editable draft
- Delete an unsubmitted draft when permitted

## Visibility

- Draft visibility follows role permissions.
- Finance, Accounting, and Investment Support do not see unsubmitted drafts.
- Read-only visibility follows the configured prototype profile.

## Visual Requirements

- Align financial amounts for fast scanning.
- Use consistent status badges.
- Give returned and overdue requests restrained visual emphasis.
- Keep row actions focused and uncluttered.
